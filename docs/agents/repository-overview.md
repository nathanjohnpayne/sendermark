# Repository Overview

**Sendermark** is a downstream **consumer** of the [mergepath](https://github.com/nathanjohnpayne/mergepath) AI-agent tooling template. It inherits mergepath's agent tooling — the review policy, CI checks, and bootstrap-provisioned workflows — and is **not** the reference implementation of the AI Agent Tooling Standard (that is mergepath).
